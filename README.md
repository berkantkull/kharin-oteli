# Khar'ın Oteli 🤘

8-bit bir resepsiyon kaosu oyunu. Khar; chopper motorcusu, metalci, canı sürekli sıkılan ve tuhaf kahkahalar atan bir otel resepsiyonisti. Sinir bozucu müşterileri tokatla, iyilerine anahtar ver!

## Nasıl oynanır

`index.html` dosyasını tarayıcıda aç. Kurulum gerekmez.

| Tuş | Hareket |
|---|---|
| `Z` / `Space` | Tokat |
| `X` / `Enter` | Anahtar ver |

- **Karen** ve **Zilci** → tokatla
- **Turist**, **Metalci** ve **Müfettiş** → anahtar ver (müfettişi tokatlamak 2 şikayet!)
- Sıkıntı barı dolarsa Khar chopper'ına atlayıp gider.
- 3 şikayet = kovuldun.
- 5'li kombo = deli kahkaha.
